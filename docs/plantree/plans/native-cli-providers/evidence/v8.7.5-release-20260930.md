## Scope Limits

This release fixes false OMP/Pi supersession caused by control-only input such
as `/model`. It does not make the complete native model-picker interaction
atomic or restore unsaved provider input after a process crash. An
authenticated real Pi TUI `/model` switch was not separately executed for
this release and remains explicit post-release qualification. Existing panes
must be restarted or reopened to load the repaired extension; no project,
conversation, or configuration migration is required.
